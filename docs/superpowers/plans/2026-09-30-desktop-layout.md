# 데스크톱 배치(시안 v41) 앱 반영 계획

시안: 디자인 시안(담당자 비공개 페이지) v41 의 '데스크톱 · 1280 × 800' 칸.
지금 앱은 768px 이상에서도 모바일 배치를 가운데 넓혀 쓴다(위 메뉴만 다름). 이 계획은 넓은 화면 전용 배치를 넣는다.

## 원칙

- **1024px 이상에서만** 두 단·격자 배치를 켠다. 768~1023px(태블릿)은 지금처럼 모바일 배치 + 위 메뉴.
- 모바일(<1024) 동작은 바꾸지 않는다. 같은 컴포넌트에 CSS 미디어 쿼리 + 필요한 곳만 넓은 화면 분기(`useMediaQuery("(min-width: 1024px)")` 한 개).
- API·라우트 그대로. 새 URL 파라미터는 정책 탭 패널 상세 하나(`detail=<slug>`)만.
- 색·토큰은 지금 청록 토큰 그대로. 검색창 하나 결정은 데스크톱에도 적용(위 검색창 → 오른쪽 패널에 검색 칸).

## 화면별

| 화면 | 1024px 이상 배치 | 주요 파일 |
|---|---|---|
| 정책 탭 | 지도 왼쪽(남는 폭 전부) + 오른쪽 목록 패널 420px. 지역을 골라도 확대하지 않고 테두리·요약 카드. 목록 줄을 누르면 패널이 그 정책 상세로(`?detail=slug`, 뒤로 = 목록), 패널 상세의 '크게 보기'는 `/policies/:slug`. 아래로 끄는 시트 대신 고정 패널 | `PolicyPages.tsx`(목록), `PolicyMapSheet.tsx`(패널 모드), `policy-map.css` |
| 정책 상세 | 두 단: 왼쪽 본문(사진·받는 혜택·기간·대상·준비물·확인할 점), 오른쪽 고정 카드(받는 것·기간·받는 방법 + 내 일정에 담기 + 공식 안내). 아래 버튼 줄은 숨김. 담기 창은 가운데 창 | `PolicyPages.tsx`(상세), `policyDetailParts.tsx`, `policy-detail.css` |
| 홈 | 가로 넘김 줄 → 격자(마감 임박 3열, 지역 사진 4열 = 미니 지도 + 7곳), 전국 공통·일정 만들기 나란히 | `HomePage.tsx`, `home.css` |
| 일정 | 목록 2열 카드. 상세 두 단: 왼쪽(머리·참여자·정책 두 절·Day 탭·타임라인) + 오른쪽 고정 카카오 지도. 여행기간 수정·⋯ 메뉴는 가운데 창. 새 일정 만들기는 가운데 한 줄(최대 560px) | `ItineraryListPage.tsx`, `ItineraryDetailPage.tsx`(배치 감싸기만), `ItineraryCreatePage.tsx`, `app.css` 일정 부분 |
| 공통 | 1024px 이상에서 `.app-container` 최대 폭을 넓힘(시안 1280 기준 1200px 안쪽) | `AppLayout.tsx`, `app.css` |

## 진행

- 모바일 네 화면을 먼저 커밋(화면별 브랜치 이어 쌓기)한 뒤, 그 위에 `feature/desktop-layout` 하나로 쌓는다.
- 화면별로 서브 에이전트(포크) 4개를 워크트리에서 나눠 돌리고 루트에서 합친다(모바일 때와 같은 방식). 공통(컨테이너 폭·`useMediaQuery`)은 루트가 먼저 만든다.
- 확인: 1024·1280·1440 폭 캡처를 시안과 나란히, 390 폭은 바뀌지 않았는지 다시.

## 검증

`npx tsc --noEmit`, `npm run test:mojibake`, `npx vitest run`, 4173 재빌드 뒤 `npm run test:e2e:containers`(1280 폭에서 넘침 없음·핵심 요소 보임 한 가지 추가), `git diff --check`.

## 하지 않는 것

태블릿 전용 배치, 관리자 화면, 로그인·마이 데스크톱(다음 시안 단계), 지도 그림 자체 변경(방금 시안 방식으로 다시 그림).

## 구현 중 확정한 것 (2026-09-30)

- 패널 상세의 주 버튼은 패널에서 바로 담기: 담기 흐름을 `usePolicyTripSheet` 훅으로 떼어 큰 상세와 같이 쓰고, 담기 창은 body 로 띄운 가운데 창.
- 넓은 화면 지도 높이: 폰 시트·탭바 몫을 빼던 높이 계산 대신 오른쪽 목록 칸 높이를 채운다(1280×800 에서 지도 619/640px).
- 정책 탭 목록 줄은 시안 문구대로: 묶음 머리에 사업 공통 문구와 설명, 묶음 안 지역 줄마다 그곳의 한 줄(`policyListText.ts`, 수집된 상세에서 규칙으로 뽑음).
  사업 공통 문구(`PROGRAM_GROUP_COPY`)는 고정 문구라 사업 내용이 바뀌면 다시 볼 것.
- 주민증 칩은 정책 탭 목록·검색 결과 카드·홈 카드에서 '상시'. 상세·패널 상세의 기간 칸만 '상시 발급'.
- 홈: '마감이 가까운 혜택'(마감이 있고 안 지난 것, 전국 포함, 상시 제외, 사업별 최대 6장) 다음에 '내 관심 지역 혜택'(관심 지역이 있을 때만).
  칩은 정책 탭과 같은 규칙, 여러 곳 묶음 카드는 정책 탭의 그 사업(`?prog=`)으로 보낸다.
- 1024px 이상 앱 틀 1200px 는 그대로 두고, 정책 탭만 화면 폭을 다 쓰게 바꾸기로 함(다음 작업).
