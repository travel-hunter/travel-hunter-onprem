# 정책 탭: 필터 · 글 검색을 지도 화면 안에서 (시안 v55)

## 문제

정책 탭에서 필터 창을 적용하거나 검색 칸의 '‘…’ 들어간 정책 N건 모두 보기'를 누르면 지도 화면을 떠나 예전 카드 목록
('전체 N개 중 M개 표시' + 카드)이 떴다. `PolicyListPage` 가 조건이 하나라도 걸리면 `showMap = false` 로 예전 목록을
그렸기 때문이다. 시안(v40~v54)에는 필터 창과 글 전체 검색 결과가 없어 새 디자인으로 옮길 때 이 두 길이 빠졌다.
휴대폰 · 넓은 화면 모두 같았다.

## 결정 (2026-10-02, 시안 v55 승인)

결과는 지도 화면 안에서 보인다. 예전 카드 목록 화면은 없앤다.

- 필터 창: 혜택 형태 · 지역 · 마감 · 금액 · 관심 정책만. 혜택 형태는 위 칩(`type`), 지역은 지도 선택(`place`)과 같은 값이다 -
  적용하면 칩을 누르고 지도를 누른 것과 같다. 예전 카테고리 여섯 가지(교통 · 숙박 · 여행상품 · 지역할인 · 이벤트 · 기타)는 뺐다.
- 마감 · 금액 · 관심 정책만 · 글 검색('모두 보기')이 새로 좁히는 조건이다. 지도 색 · 건수 · 칩 건수 · 지역 카드 · 목록이 같이 좁아진다.
- 아래 단추는 'N건 보기'로 미리 센다. 맞는 게 없으면 '맞는 혜택 없음'(누를 수 없음).
- 걸린 조건은 목록 머리 아래 한 줄('‘숙박’ 검색 · 마감 30일 이내 · 관심 정책만')과 ✕. 필터 단추에 조건 수('필터 2').
  조건으로 목록이 비면 목록 안에 안내와 '조건 모두 풀기'.

## 조건은 주소 밖에 둔다

지도 층(지역 · 시군 · 사업 · 칩 · 시트 자리)은 주소에 두고 층이 늘 때만 기록을 쌓는다(`useBrowseHistory`). 조건까지
주소에 두면 쌓아 둔 앞 칸이 조건 없는 주소라 기기 뒤로가기가 조건을 지운다. 조건은 층이 아니므로(칩처럼) 뒤로가기로
풀리면 안 된다 - `components/map/policyConditions.ts` 의 작은 저장소에 두고 탭의 sessionStorage 에 남긴다. 상세에
다녀와도, 새로 고쳐도 남고 ✕ 로만 푼다.

예전 주소: `region=`(지역 필터)은 지도 선택으로 읽고, `category` · `period` · `amount` · `saved` 는 쓸 때 지운다.

## 지운 것

예전 카드 목록 화면과 그 부품: `PolicyListCard`(+ 시험), 목록 썸네일 `PolicyThumbPhoto`, 카테고리 필터 도우미, 목록 정렬
(`sortPoliciesForList`). 예전 목록 CSS(`.policy-list-card` 등)는 이번에 지우지 않았다 - 죽은 CSS 정리는 따로.

## 시험

- 필터 창의 지역 · 형태가 지도 선택이 되는지, 마감 조건이 지도 · 목록을 같이 좁히는지, 화면 안 ‹ 로 층을 걸어도 조건이
  남는지, ✕ 로 풀리는지, 미리 세는 단추, 글 검색, 예전 `region=` 주소(`policies.test.tsx`).
- 관심 정책만(`mypage.test.tsx`), 주소 쓰기의 옛 키 지우기(`policyBrowse.test.ts`).
- 4173 실측(390 · 1440): 필터 적용 · 조건 줄 · ‹ 뒤에도 조건 · ✕ · '모두 보기', 예전 목록 없음, 가로 넘침 없음.

## 남는 것

- 휴대폰 반반 화면에서 지역을 고르는 것은(지도 누르기와 같이) 같은 층이라 기록을 덮어쓴다 - 기기 뒤로가기는 정책 탭을 떠난다.
  예전부터의 층 규칙 그대로다.
- 조건은 탭(sessionStorage)에 남아 다른 탭에서 정책 탭으로 돌아와도 걸려 있다 - 조건 줄과 ✕ 가 늘 보인다.
