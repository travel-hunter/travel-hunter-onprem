# 정책 탭 모바일 수정 — 하단 메뉴, 탭 하이라이트, 자동 복귀

브랜치 `fix/policy-tab-bottom-tabs-hidden`, 베이스 `origin/develop`(932eb79). 프런트만.

## 1. 하단 메뉴가 사라짐 (회귀)

**증상.** 모바일 폭에서 정책 탭에 들어가면 하단 메뉴가 안 보인다.

**원인.** #76 에서 한 페이지 모션을 만들며 정책 페이지(시트)를 탭바보다 위 레이어로 올렸다(시트 95 · 탭바 90).
"올라오는 페이지가 탭바를 덮는다"는 생각이었지만, 시트는 `bottom: 0` 까지 내려가 있어 닫혀 있을 때도
화면 아래 92px(손잡이 20 + 탭바 자리 72)에 걸쳐 있다. 불투명한 페이지가 올리기도 전에 탭바를 가렸다.
768px 이상은 탭바가 없어 그때 확인에서 드러나지 않았다.

**수정.** 겹침 순서를 되돌린다 - 딤 69 · 시트 70 · 탭바 90 · 떠 있는 뒤로가기 91.
탭바는 제 `transform`·`opacity` 로 아래로 빠지며 옅어지므로 페이지가 덮어 줄 필요가 없다.
페이지 "뒤로" 가라앉게 하려면 닫힌 시트가 탭바 자리를 비워야 하는데, 불투명한 한 장이라 불가능하다.

## 2. 지도를 탭하면 네모 박스가 번쩍임

**원인.** 지역(`.thmap-rg`)과 이름표(`.thmap-lbl`)는 `cursor: pointer` 가 걸린 SVG 그룹이다. 모바일 브라우저는
탭 하이라이트를 요소의 외곽 사각형으로 칠한다 - 지역 모양과 상관없는 네모가 지역과 글자 양쪽에서 번쩍인다.
프로젝트에 `-webkit-tap-highlight-color` 처리가 없었다.

**수정.** 지도 칸(`.thmap-host`) 안에서만 투명으로. 눌린 표시는 지역이 솟는 것으로 이미 주고 있고,
키보드 포커스 표시(`focus-visible`)는 건드리지 않는다.

## 3. 어중간한 자리에 세워 둔 페이지의 자동 복귀

**배경.** 9/20 에 "중간 전에 놓으면 도로 올라가는" 스프링백을 없애고 놓은 자리에 멈추게 했다. 써 보니
지도를 잠깐 내려다본 뒤 매번 손으로 다시 올려야 했다.

**사용자 결정(2026-09-21).** 놓은 자리에 잠깐 머물렀다가 가까운 끝으로 스스로 돌아간다.
머무는 시간은 1.2초로 시작했다가 확인 뒤 **마지막으로 만진 때부터 0.3초**로 줄였다.

- 중간보다 위면 검색창 밑으로 올라붙고, 아래면 지도로 내려간다(위쪽만 하면 밑에서는 영영 서 있게 된다).
- 머무는 동안 다시 만지면(휠·손잡이·터치) 취소되고, 손을 떼면 다시 센다.
- 휠은 손을 떼는 순간이 없어 굴림이 멎었다고 보는 140ms 가 먼저 들어간다.
- "끌다가 중간을 건너가면 즉시 끝까지"는 그대로다.

## 4. 휠 감도

페이지를 내리려면 휠을 여러 번 굴려야 했다. `WHEEL_DAMP` 0.8 → **1.6**(사용자 요청: 두 배).
한 칸(deltaY 100)에 160px 이라 일반 화면 높이에서는 두 칸이면 중간을 건너가 지도로 내려간다.
원래 0.8 이었던 이유는 "1 이면 한두 번에 닫혀 손이 미끄러진다"였는데, 지금은 중간 전에 멈추면 0.3초 뒤
스스로 올라붙으므로 실수로 건드린 정도는 되돌아온다. 터치 끌기는 1:1 이라 이 값과 무관하다.
테스트는 휠 입력을 '페이지가 움직일 px'(`wheelBy`)로 주게 바꿔 감도를 다시 만져도 깨지지 않는다.
